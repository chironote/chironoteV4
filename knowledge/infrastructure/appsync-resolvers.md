Any resolvers that you add in this directory will override the ones automatically generated by Amplify CLI and will be directly copied to the cloud.
For more information, visit [https://docs.amplify.aws/cli/graphql-transformer/resolvers](https://docs.amplify.aws/cli/graphql-transformer/resolvers)

## Recording Telemetry Ingestion

`Mutation.createRecordingTelemetryEvent.req.vtl` is a deliberate override, not generated output. It enforces the persisted telemetry allowlist, safe formats/ranges, event vocabulary, and authentication-specific source namespace; preserves the producer-reported time separately; assigns id, authoritative occurrence time, timeline key, and expiry server-side; preserves idempotent retries; and writes a GraphQL-hidden per-job producer fingerprint for abuse investigation.

Whenever the telemetry schema changes, update the client validator, resolver allowlist/vocabulary, GraphQL model, runbook, and resolver/client tests together. Run `amplify api gql-compile` and confirm the override is copied into `build/resolvers`. Never edit the ignored build copy directly.
